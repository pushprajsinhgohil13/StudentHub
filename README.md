# 🎓 StudentHub

### A Student Portal Website

A multi-page student portal built as a Web Development Framework (WDF)
practical project at CHARUSAT University.

[Features](#-features) · [Tech Stack](#-technologies-used) · [Project
Structure](#-project-structure) · [Run Locally](#-how-to-run)
:::📌 About the Project
StudentHub is a student portal interface that brings common academic
sections together in one place. It includes pages for a dashboard,
courses, attendance, assignments, events, library resources, student
profile, and results.

The repository also contains practical-work folders and a dynamic
version of the StudentHub project.
✨ Features
- 🔐 Student login page
- 🏠 Dashboard
- 📚 Courses
- 📝 Assignments
- 📅 Attendance
- 📖 Library resources
- 🎉 Events
- 👤 Student profile
- 📊 Results
- 🧭 Multi-page navigation
- 🎨 Styled interface using CSS
🛠️ Technologies Used
  Technology                          Purpose

  CSS3                            Styling, layout, and visual design

  JavaScript                      Used where applicable in the
                                      dynamic version for client-side
                                      interactions

  Git & GitHub                    Version control and source-code

The root-level version is built with HTML and CSS. Check the files
inside StudentHub_Final_Dynamic for the implementation used by the
dynamic version.

🚀 How to Run
Option 1: Open directly
1. Open or download this repository.
2. Open the project folder.
3. Open index.html in your web browser.
Option 2: Clone with Git
git clone https://github.com/pushprajsinhgohil13/StudentHub.git
cd StudentHub
Then open index.html in your browser.

For the dynamic version, open StudentHub_Final_Dynamic and follow any
setup instructions included in that folder.
🎯 Project Objectives
- Practice building a multi-page website.
- Learn how to structure content with HTML.
- Apply CSS for page styling and layout.
- Create navigation between related pages.
- Design a central place for student academic information.
🔮 Future Improvements
- Add secure, functional student authentication.
- Connect the interface to a database.
- Add backend APIs for courses, attendance, assignments, and results.
- Improve accessibility and mobile responsiveness.
- Add form validation and useful interactive features.
- Deploy the website so it can be accessed online.
