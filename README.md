# 🎓 StudentHub 

StudentHub is a simple student portal website developed as a **Web Development Framework (WDF)** practical project. It provides a clean and user-friendly interface for students to access academic information such as courses, attendance, assignments, events, library resources, profiles, and results.

---

## 📌 Features

- 🔐 Student Login Page
- 🏠 Dashboard
- 📚 Courses
- 📝 Assignments
- 📅 Attendance
- 📖 Library
- 🎉 Events
- 👤 Student Profile
- 📊 Results
- 🎨 Responsive UI using HTML & CSS

---

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/PushprajsinhGohil/WDF-Practical.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.
